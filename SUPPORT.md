# Getting help

- **How do I…?** Start with the documentation at [quicx.dev/docs](https://quicx.dev/docs/installation): installation, configuration, the QXP protocol, the Java client and the CLI.
- **Something is wrong.** Open an issue in the repository it concerns: [the daemon](https://github.com/anastassow/Quicx/issues), [the Java client](https://github.com/Quicx-Engine/Quicx-Java/issues), [the website](https://github.com/Quicx-Engine/quicx-website/issues).
- **A security problem.** See [SECURITY](SECURITY.md); please do not report it in public.
